## 第二部分：完整填寫範例（教材虛構，繳交時刪除）

以下示範一位學生完成 GreetingApp 後，請 AI 檢查程式。情境中的程式原本已符合需求，所以不需要為了使用 AI 而刻意修改。

### 1. 何時、如何使用 AI？

- 日期：2026/09/18。
- 使用方式：本人操作。
- 工具名稱：ChatGPT。

### 2. 我問了什麼？

我已完成 GreetingApp，想確認從 C# 移植到 Java 的方法是否符合要求。我貼上程式並提問：

```text
我學過 C# WinForms，正在練習 Java。
以下方法是否會依傳入姓名回傳正確的問候字串？
請用 Ada、Grace、Ada Lovelace 說明預期結果。
方法內不應輸出，也不要新增 GUI 或其他功能。

static String buildGreeting(String name) {
    return "Hello, " + name + "!";
}
```

### 3. AI 建議什麼？我如何決定？

- AI 回覆重點：方法使用參數組合字串並回傳，符合要求；Java 使用 `String`，與 C# 的 `string` 寫法不同。建議以三個不同姓名測試。
- 我的決定與修改：採用三筆測試的建議，保留原程式，沒有修改方法。因為方法已使用傳入的姓名，而不是把 Ada 寫死；是否真的正確，還要自行執行確認。

### 4. 我如何親自驗證？

- 操作方式：用 VS Code 開啟當日的 Java 專案，確認 main 依序呼叫三個姓名並輸出回傳值，儲存檔案後點 main 上方的 Run，在終端機讀取結果。

| 姓名 | 預期輸出 | 我的實際輸出 | 是否符合 |
|---|---|---|---|
| Ada | Hello, Ada! | Hello, Ada! | 是 |
| Grace | Hello, Grace! | Hello, Grace! | 是 |
| Ada Lovelace | Hello, Ada Lovelace! | Hello, Ada Lovelace! | 是 |

- 檢查程式：`buildGreeting` 只有回傳字串，沒有 `System.out.println`；`main` 才把回傳值印出。執行時得到三行問候，沒有額外空白行，姓名中的空白也有保留。

### 5. 我學到什麼？

AI 說程式正確後，我仍要親自測試；使用不同姓名，才能檢查結果是否真的來自參數。
