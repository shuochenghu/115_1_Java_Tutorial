# 第 12 週驗證紀錄（Codex 版本）

日期：2026-11-19。實際範圍為本週教材生成與本機驗證；課堂時間仍為備課估計。

## 環境與操作

Windows，OpenJDK `22+36-2370`、`javac 22`、Python 3.14。使用 UTF-8 與 `-Xlint:all`，不加入固定 `--release`、`-source`、`-target`。CLI 擷取 Java 輸出時明確指定 stdout／stderr 為 UTF-8，正規化 Windows 換行；沒有把這些維護參數列為學生語法要求。

在本目錄執行：

```powershell
python -X utf8 tools/verify.py
```

工具在新的系統暫存目錄分開編譯，不讀取第 11 週、不使用舊 out，結束自動清理。詳細可重跑項目見 [tools/README](tools/README.md)。

## Java 與完成路徑

- examples、兩組 starter、兩組 teacher、作業與 AI 副本分開編譯；成功版本無警告。
- ParseDemo 捕捉／未捕捉與合法／格式錯誤完整輸出；未捕捉版只印轉換前，另有 NumberFormatException。FinallyTrace 正常與錯誤兩條收尾路徑。
- 只填入 A2、A3、B1、B2 指定區塊即可完成學生版；A2 單獨完成時入口仍顯示 A3 未接上。
- 額度固定六筆的七行完整輸出，以及作業六行加摘要 3／3／0。
- 課堂與作業各 13 組逐行比對：1、5、0、-1、6、空字串、純空白、前後空白的 2、2147483648、2.5、5→5→1→6、空字串→0→前後空白的 2、空陣列；涵蓋拒絕後成功、零額度與同時違規的優先訊息。另建兩個額度物件，第一個用完仍不影響第二個的 10 頁。
- AI 錯誤重現第五筆 -2、最後 -4；實際把不足判斷移到扣除前，再以同六筆核對七行結果。
- 交換 catch 順序與省略 join 受檢例外處理，兩份隔離副本皆編譯拒絕。
- 學生完成的執行緒版執行五次，教師版一次：每次完整 8 行、名稱對應、各自 1→2→3、結束訊息最後。不要求排程不同。直接 run 版六行皆在 main，完整順序符合預期。
- 以教師專用 latch 控制工作保持存活，預先中斷等待者，再執行由教師原檔抽出的 catch 本體；確認有中斷提示、恢復旗標 true，且未走正常結束。最後釋放工作並等待清理；此基礎設施不列學生要求。
